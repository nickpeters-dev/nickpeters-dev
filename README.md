## How I work

AI tools write much of the implementation. **I define the requirements, direct development, review the resulting behavior, and decide what is ready to ship.** I'm deliberately building stronger independent coding and debugging skills alongside that work.

- **Written expectations:** Architecture and engineering standards guide each AI coding session, including explicit stop-and-ask conditions.
- **Context before changes:** Relevant code is inspected before edits; changes are scoped and reviewed on branches.
- **Verification beyond AI assertions:** Financial calculations are checked through known-answer tests, boundary tests, and independent reference implementations where applicable.
- **Real-world feedback:** I use the applications myself, inspect preview deployments, and record why important decisions were made.
